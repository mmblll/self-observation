# 自我观察

一个可以反复做、慢慢看自己变化的安卓小应用。

有些话自己不好意思承认，换成一道题，可能就愿意认真想一下。

**[下载最新版 APK](https://github.com/mmblll/self-observation/releases/latest)** · Android 8.0 及以上

## 能测些什么

七宗罪和七美德放在一起测。十四项各自计分，最后选出一个本次代表人物，配上对应的图片。再做一次，人物也可能跟着变。

除此之外，还有四维性格倾向、大五人格、依恋倾向、价值观、边界感、冲突处理、拖延、压力应对、完美主义，以及单独列出的 IPIP 五因素原题版，一共 11 项测试。

- 原创题库有 5000 个条目，包含同一情境下的不同反应。每轮随机抽题，同一题族一轮只出一道。
- 做到一半可以退出，下次接着来。完成的结果会留下记录，也能删除、恢复或彻底删掉。
- 每项测试都有雷达图、文字分析和建议，可以回头看看几次结果有什么不同。
- 结果可以生成图片，预览后再决定要不要分享。
- 七宗罪的分享点评嘴比较损，七美德温和一点。它说的是这次回答，不是给你定性。

## 安装和更新

打开上面的下载页，找到 `self-observation-v1.2.2.apk`。不要下载 GitHub 自动放在下面的 `Source code` 压缩包，那不是安装包。

下载后点开安装。如果手机提示不允许安装这个来源，给当前下载应用开启安装权限再试。

已经装过之前版本的，直接覆盖安装。想留住记录，就不要先卸载，也别清除应用数据。

## 记录放在哪里

都在你自己的手机里。不用注册，没有云同步，也不会把答题记录上传到服务器。分享图片需要你自己点，没点就不会发出去。

卸载应用或清除数据，会丢掉本机记录。目前没有备份导入导出，换手机也不会自动带过去。

## 有几句话先说清楚

这些结果适合拿来想想自己，不是诊断。原创题和辅助中文译文没有做过心理测量验证，不能当成正式量表。IPIP 的 50 道英文原题单独列着，不和原创题混在一起算。

题目会换，最近的经历也会影响回答。两次分数不一样，先看看发生了什么，不用急着给自己贴标签。

这个仓库目前只放安装包和说明，源码暂时不公开。
